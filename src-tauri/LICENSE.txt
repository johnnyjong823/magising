六、隱私政策
1. 本軟體不需要註冊帳號，不收集你的個人資料，也沒有廣告或使用追蹤。
2. 為了找歌詞，本軟體會把「正在播放的歌名、歌手與歌曲長度」（LRCLIB 另含專輯名稱），以及你手動搜尋時輸入的關鍵字，傳送給上面列出的歌詞服務。其中酷狗音樂的歌曲搜尋使用未加密的 HTTP 連線。這些服務如何處理收到的資料，依它們各自的隱私政策。
3. 你可以在「設定 → 歌詞來源」關掉任何一個或全部歌詞服務。全部關掉時，本軟體只使用你電腦裡的 .lrc 檔，不會把歌曲資訊傳出去。
4. 本軟體會讀取 Windows「媒體控制」裡播放器提供的歌曲資訊（歌名、歌手、播放進度、封面），只用來顯示字幕，不會傳出。
5. 設定、歌詞快取與紀錄檔只存在你的電腦（%APPDATA%\MagiSing\；免安裝版則在程式旁的 data\ 資料夾），不會上傳。網頁元件（WebView2）的暫存檔在 %LOCALAPPDATA%\com.magising.app\。解除安裝時勾選「刪除應用程式資料」會一併刪除這兩個資料夾，也可以自己手動刪除。
6. 本軟體會註冊全域快捷鍵；開機自動啟動預設關閉，要你自己打開。外部連結（網站、GitHub、斗內、意見回饋）只有在你按下按鈕時才會用瀏覽器開啟。
7. 本軟體預設在啟動時與之後每天一次連到 GitHub（api.github.com）查詢最新的版本號，請求裡只有程式名稱與版本，不含歌曲或使用資料；有新版時只會提示你，不會自動下載或安裝。可以在「設定 → 其他」關掉。GitHub 如何處理連線紀錄，依 GitHub 的隱私政策。
